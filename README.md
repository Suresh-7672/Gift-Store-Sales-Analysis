
# Gift Store Sales Analysis Dashboard

## Overview
An Excel-based sales analytics project that analyzes customer, product, and order data to understand revenue, sales performance, delivery time, customer behavior, products, occasions, and locations.

## Business Questions
- What is total revenue and number of orders?
- Which products/categories generate the most revenue?
- Which locations contribute the most sales?
- How long does delivery take on average?
- How do sales vary by month, day, hour, and occasion?
- Which customer/product dimensions can support business decisions?

## Dataset
The project contains:
- `Customers` — customer profile and contact information
- `Orders` — 1,000 order-level records with quantity, dates, location, occasion, price, revenue, and delivery metrics
- `Products` — product master data
- `Dashboard` — Excel dashboard sheet
- `Sheet1` — supporting summary/pivot calculations

## Key Results
- Total orders: **1,000**

## How to Use
1. Open `Gift_Store_Sales_Dashboard.xlsx` in Excel 2019 or later.
2. Review the source sheets: Customers, Orders, and Products.
3. Review the supporting calculations in `Sheet1`.
4. Open the `Dashboard` sheet to view the dashboard.
5. If the source data changes, refresh the PivotTables/PivotCharts as applicable.
